Aplicativo Física Teórica para Windows (instalador e versão portátil) e Android (APK).

- **Android:** baixe o `.apk` no celular, abra e autorize a instalação desta fonte.
- **Windows:** use o instalador `Setup` ou a versão `Portatil`. Sem assinatura digital, o SmartScreen pode avisar: "Mais informações" → "Executar assim mesmo".

Para descrever as novidades de uma versão, crie `release-notes/vX.Y.Z.md` antes de publicar.
