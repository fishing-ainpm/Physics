## Novidades da versão 0.3.0

### ✅ Editor de fórmulas com validação
O editor agora só aceita expressões matemáticas. Texto comum é recusado com uma mensagem clara, sem criar uma variável para cada palavra.

| Você digita | O app responde |
|---|---|
| `sua mãe de quatrão` | Isto parece texto comum, não uma fórmula |
| `F = m a` | Falta um operador entre “m” e “a”. Para multiplicar, use m*a |
| `F = m(a+b)` | “m(…)” não é uma função conhecida. Para multiplicar, use m*(…) |
| `mãe = 2` | Nome com acento: use letras sem acento (para gregas, `lambda`, `theta`) |
| `y = sin + 1` | “sin” é uma função; use sin(…) |

Continuam funcionando os nomes científicos (`v0`, `T_h`, `lambda_max`, `gamma`), as constantes físicas (`c`, `G`, `hbar`, `kB`…), `2x`, `mod`, `!` e as funções comuns. A mesma regra vale para as funções da página de Gráficos.

### 🖤 Visual novo
- Fundo preto, painéis de vidro translúcido discretos e destaques em branco.
- Gráficos, ícone do app e tela de abertura no mesmo estilo.

### 📱 Tela deitada no Android
- Em **Configurações** (⚙ na navegação), escolha a orientação: **Automática**, **Retrato** ou **Paisagem**.
- Com o celular deitado, o layout usa duas colunas e o teclado matemático fica mais baixo, com 12 teclas por linha.
- O campo onde você está digitando rola para ficar visível acima do teclado matemático.

## Downloads

| Arquivo | Plataforma |
|---|---|
| `FisicaTeorica-0.3.0.apk` | Android 7.0 ou superior |
| `FisicaTeorica-Setup-0.3.0.exe` | Windows 10/11 (64 bits), instalador |
| `FisicaTeorica-Portatil-0.3.0.exe` | Windows 10/11 (64 bits), roda sem instalar |

**Android:** baixe o APK no celular, abra e autorize a instalação desta fonte. Quem já tem a 0.2.0 instalada pode instalar por cima, sem desinstalar. Se o Play Protect avisar, toque em "Instalar mesmo assim".

**Windows:** o executável não tem assinatura digital, então o SmartScreen pode avisar na primeira execução: "Mais informações" → "Executar assim mesmo".
