Aplicativo de desktop para Windows (64 bits).

- **FisicaTeorica-Setup-0.1.0.exe**: instalador (cria atalho na área de trabalho e no menu Iniciar).
- **FisicaTeorica-Portatil-0.1.0.exe**: versão portátil, roda sem instalar.

O executável não é assinado digitalmente; o Windows SmartScreen pode exibir um aviso. Clique em "Mais informações" → "Executar assim mesmo".
